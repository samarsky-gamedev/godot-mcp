# Материалы лабораторных работ

Тема: «MCP сервер для игрового движка Godot».

Студенты: Павлов С.К., Трещев О.Д., ИДБ-25-15.
Преподаватели: Лобанов О.А., Кайкова И.В.

- `Отчёт.docx` и `Отчёт.pdf` — описание проекта, сравнение, UML, архитектура, информационные потоки, IDEF0, IDEF3, ARIS и результаты проверки.
- `Защита по заданиям.docx`, `.pdf` и `.txt` — речь по заданиям отчёта, распределённая между Степаном и Олегом. В каждом блоке указано, что показать, и приведены вероятные вопросы с ответами.
- `Защита.pptx` — дополнительные слайды. Основной сценарий защиты не зависит от презентации.
- `../demo-defense/` — отдельный демонстрационный проект Godot и журнал MCP-вызовов.
- `../evidence/acceptance.json` — результат интеграционного теста.

Для проверки и повторной демонстрации следуйте корневому README. Запускайте демонстрацию в новой папке. Код основной игры не нужен.

Тест подтверждает ограниченный технический сценарий, а не все возможности сервера или качество полноценной игры. Коммерческие цены и показатели в отчёте являются учебными допущениями.

Фотографии участников не включены: для защиты по отчёту используются имена и распределение ролей. Макет показан отдельным проектом, а не видеозаписью.
