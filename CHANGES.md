# Изменения учебного прототипа

База: Coding-Solo/godot-mcp, commit `1209744fad78f3998f98c7394fd0f6ef50da5281`.
Исходное авторство Solomon Elias и MIT LICENSE сохранены. README базы — README_UPSTREAM.md.

Собственные дополнения учебного прототипа, реализованные с помощью ИИ агента:

- `src/extensions.ts`: два MCP инструмента, валидация параметров, таймауты и отчёт по стадиям.
- `src/scripts/godot_inspect.gd`: чтение SceneState сохранённой сцены без instantiate.
- `tests/integration.test.mjs`: клиент MCP, реальные операции Godot, успешный и ошибочный сценарии.
- `scripts/demo.mjs`: воспроизводимая сборка демонстрационной сцены через MCP.
- `examples/`: настройки Codex и Claude Code, без автоматического изменения настроек пользователя.
- Регистрация новых инструментов в `src/index.ts`, копирование служебного скрипта при сборке.

14 исходных инструментов сохранены. Никакой регистрации платных пользователей, биллинга,
универсального отката, визуального управления игрой и коммерческой поддержки пока нет.
Локальный запуск проверен на Windows / Godot 4.7.1. Подключение к настоящим сессиям
Codex и Claude Code ещё требует проверки; тест использует официальный MCP SDK client.

Прототип выполняет доверенные проекты с правами пользователя; это не песочница.
Ограничение scenePath действует на новый инструмент инспекции, не является общей
защитой всех унаследованных инструментов. Перед публичным релизом нужны проверка
зависимостей, обработка чужих проектов и матрица совместимости.
